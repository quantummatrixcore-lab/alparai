# E5 — Accessibility CI Gate

**Date**: 2026-07-12  
**Tool**: `@axe-core/playwright` v4.12.1

## Scope

5 critical pages tested with WCAG 2.2 AA tags:

- `/en` (Home)
- `/en/incidents` (Incident list)
- `/en/ratings` (K-BENCHMARK ratings)
- `/en/transparency` (Transparency report)
- `/en/methodology/k-benchmark` (Methodology)

## Threshold

- **0 critical violations** (impact: "critical")
- **0 serious violations** (impact: "serious")

Minor violations are tracked but do not block CI.

## Running

```bash
npx playwright test tests/e2e/a11y/ --reporter=html
```

## CI Gate

Failing this check blocks Vercel promotion. Run `test:e2e -- --project=chromium --grep "Accessibility"` in CI pipeline.
