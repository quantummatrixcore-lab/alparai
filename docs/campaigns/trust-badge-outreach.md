## 2. Technical Integration Specification (`badge.js`)

The ALPAR AI Trust Badge is a lightweight, zero-dependency client-side script (`public/badge.js`) designed to render dynamic verification seals directly on provider dashboards, documentation portals, and model card pages.

### HTML Embed Snippet (Default Dark Mode)

```html
<!-- ALPAR AI Dynamic Trust Badge Embed -->
<script src="https://alparai.com/badge.js" data-provider="openai" data-theme="dark" async></script>
<div id="alparai-trust-badge" data-provider="openai" data-theme="dark"></div>
```

### Next.js / React Component Embed Snippet

```tsx
import Script from "next/script";

export function AlparTrustBadge({ providerId = "openai" }: { providerId?: string }) {
  return (
    <>
      <div id="alparai-trust-badge" data-provider={providerId} data-theme="auto" />
      <Script
        src="https://alparai.com/badge.js"
        strategy="afterInteractive"
        data-provider={providerId}
        data-theme="auto"
      />
    </>
  );
}
```
