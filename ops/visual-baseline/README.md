# Visual Baseline Screenshots

Generated by running `pnpm test:visual -- --update-snapshots` with a running dev server.

**Prerequisites:**

```bash
pnpm dev          # Terminal 1
pnpm test:visual  # Terminal 2 (first run creates baseline)
```

On CI, baselines are committed and subsequent runs compare against them.
To update baselines after intentional UI changes: `pnpm test:visual -- --update-snapshots`
