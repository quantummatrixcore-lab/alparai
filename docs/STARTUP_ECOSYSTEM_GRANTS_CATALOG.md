## 1. Bulut & Genel Altyapı Devleri

### 🟢 1. Google for Startups Cloud Program (AI-First Stream)

- **Kapsam:** $2,000 (Start Tier - Bootstrapped) ila **$350,000** (AI-First Scale Tier - 2 yıl boyunca).
- **Hangi Hizmetleri Kapsar:** Google Cloud Platform (GCP), Vertex AI, Gemini API, Firebase.
- **ALPAR AI Stratejisi:** EU AI Act uyumluluk taramaları ve LLM moderasyonu (Gemini 1.5 Pro/Flash) için Vertex AI kredilerini kullanma.
- **Başvuru Şartı:** Resmi şirket e-postası (`ercument.erden@alparai.com`), GCP Account ID.
- **Başvuru Linki:** [cloud.google.com/startup](https://cloud.google.com/startup)

### 🔵 2. Microsoft for Startups Founders Hub

- **Kapsam:** **$150,000'a kadar** kademeli Azure Kredisi + GitHub Enterprise + Microsoft 365.
- **Hangi Hizmetleri Kapsar:** Azure Virtual Machines, Postgres, **Azure OpenAI Service** (GPT-4o, DALL-E 3, Embeddings).
- **Kritik Avantaj:** Ayrı OpenAI kredisi yerine, Azure OpenAI kullanımı bu $150k Azure kredisinden düşülür.
- **Başvuru Şartı:** Şirket zorunluluğu yok (pre-seed aşaması kabul edilir), 3 iş gününde onay.
- **Başvuru Linki:** [startups.microsoft.com](https://startups.microsoft.com)

### 🟧 3. AWS Activate

- **Kapsam:** $1,000 (Founders / Bootstrapped) ila **$100,000 - $200,000** (Portfolio / Accelerator Destekli).
- **Hangi Hizmetleri Kapsar:** EC2, S3, RDS, AWS Bedrock (Claude, Llama 3, Titan modelleri).
- **Başvuru Şartı:** Çalışır vaziyette web sitesi (`alparai.com`), `alparai.com` uzantılı kurumsal mail.
- **Başvuru Linki:** [aws.amazon.com/startups](https://aws.amazon.com/startups)

## 2. Yapay Zekâ & Model Sağlayıcıları

### 🟣 4. Anthropic Startup Program & Research Grants

- **Kapsam:** $1,000 – $25,000 API Kredisi (VC destekliler için $250k'ya kadar) + Öncelikli Rate Limit.
- **Özel Araştırma Hibesi:** _AI for Science & Safety_ kapsamında araştırmalar için **$50,000** doğrudan Claude API hibesi.
- **ALPAR AI Stratejisi:** ALPAR AI "AI Safety & Incident Governance" kategorisinde olduğu için doğrudan güvenlik/etik gerekçesiyle başvurulabilir.
- **Başvuru Linki:** [anthropic.com/startups](https://www.anthropic.com/startups)

### 🟢 5. NVIDIA Inception Program

- **Kapsam:** Hisse talep etmeyen (non-equity) AI hızlandırma programı.
- **Avantajlar:**
  - NVIDIA Deep Learning Institute (DLI) ücretsiz kursları ve sertifikaları.
  - Özel GPU cloud partnerlerinden indirimli/ücretsiz GPU süresi.
  - NVIDIA SDK & TensorRT teknik desteği ve yatırımcı ağına erişim.
- **Başvuru Şartı:** AI/Data Science alanında çalışan resmi şirket, kurumsal mail (`@alparai.com`).
- **Başvuru Linki:** [nvidia.com/startups](https://www.nvidia.com/en-us/startups/)

### ⚪ 6. OpenAI Researcher Access Program & Partner Credits

- **Kapsam:**
  - **Ramp / Partner Portalı:** $2,500 API kredisi (Ramp Corporate Card perk'ü üzerinden).
  - **Researcher Access Program:** Yapay zekâ güvenliği, sorumlu yaygınlaştırma ve toplumsal etki araştırmaları için **$1,000** doğrudan API hibesi.
- **ALPAR AI Stratejisi:** AI İhlal Veritabanı ve Şeffaflık vizyonumuz "Researcher Access" kriterlerine tam uyar.
- **Başvuru Linki:** [openai.com/research/overview](https://openai.com/research/overview)

## 3. Geliştirici Araçları & Platformlar

- **Kapsam:** $10,000'a kadar GitHub platform kredisi + 1 Yıl Ücretsiz GitHub Enterprise (20 koltuk) + GitHub Copilot.

- **Başvuru Şartı:** Partner (YC, Techstars, Stripe Atlas, Mercury veya VC) referansı/ortaklığı.
- **Başvuru Linki:** [github.com/enterprise/startups](https://github.com/enterprise/startups)

### 🖤 8. Vercel for Startups & Open Source Sponsorship

- **Kapsam:** Pro/Enterprise paketlerinde aylık kullanım kredileri.

- **ALPAR AI Stratejisi:** Next.js 15 tabanlı platformumuz için Vercel Open Source veya Vercel Startups kulvarından başvuru yapılabilir.
- **Başvuru Linki:** [vercel.com/startups](https://vercel.com/startups) & [vercel.com/oss](https://vercel.com/oss)

- **ALPAR AI Stratejisi:** Projede kullanılan Supabase PostgreSQL, Storage ve Auth altyapı faturasını sıfırlama.
- **Başvuru Linki:** [supabase.com/startups](https://supabase.com/startups)
