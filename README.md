## 🚀 Quickstart

### Prerequisites
* **Node.js:** `>= 20.0.0`
* **Package Manager:** `pnpm >= 9.12.0`
* **Database:** DeHost PostgreSQL with Row-Level Security (RLS) enabled
* **Network Rule:** Port 22 is strictly disabled across all deployment environments

### 1. Repository Setup
```bash
# Clone the repository
git clone https://github.com/quantummatrixcore-lab/alparai.git
cd alparai

# Install strictly locked dependencies
pnpm install
```

### 2. Environment Configuration
```bash
cp .env.example .env.local
# Configure your DeHost PostgreSQL credentials, Sovereign Bridge secrets, and encryption salts
```

### 3. Local Crucible Verification
Before executing code or proposing mutations, run the mandatory verification pipeline:
```bash
# Static analysis and type safety
pnpm lint
pnpm typecheck

# Unit and contract tests
pnpm test

# Full validation pass
pnpm validate
```

### 4. Running the Development Server
```bash
pnpm dev
# Open http://localhost:3000 in your browser
```

## 🛡️ Security, Privacy & Network Sovereign Policy

1. **Port 22 Absolute Ban:**  
   Port 22 is globally vulnerable and prohibited across all internal infrastructure, remote machines, and CI/CD agents. Remote ingress is exclusively permitted over WireGuard Mesh VPNs (`10.99.0.0/24`), Cloudflare Zero-Trust tunnels, or authenticated high-port mTLS proxies.
2. **Zero-Knowledge PII Ingestion:**  
   No unhashed national identification numbers, credit card data, email addresses, or unencrypted IP addresses are ever written to database logs or persistence layers. The **PII Guardian** sanitizes all telemetry at the client boundary.
3. **Database Sovereignty (RLS):**  
   Every table is secured by DeHost PostgreSQL Row-Level Security (RLS) policies. Client-side database modifications are strictly prohibited; all state mutations route through authenticated Server Actions.
4. **Responsible Disclosure:**  
   Security vulnerabilities must be reported directly to `security@alparai.com`. Reports are acknowledged within 24 hours in accordance with our ISO/IEC 29147 coordinated disclosure policy.
